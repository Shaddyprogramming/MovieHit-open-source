### Pico 2W Pong Game
WiFi-enabled Pong game for Raspberry Pi Pico 2W with robust CircuitPython implementation.

**Location**: `/pico-2w-pong/`

**Features**:
- Runs reliably as `code.py` (auto-startup)
- Physical button controls
- Web-based remote controls
- LED status indicators
- 60 FPS gameplay with AI opponent
- Comprehensive error handling and recovery
- Non-blocking network operations
- Memory optimization for CircuitPython

See `/pico-2w-pong/README.md` for complete setup instructions.
